# Open Arc Help Center

- **Getting started and keyboard shortcuts**: Help ▸ Getting Started and Help ▸ Essential Keyboard
  Shortcuts in the app.
- **Profiles**: see [Profiles](profiles.md).
- **Import from Arc, Chrome or Safari**: File ▸ Import, or the import step of the welcome screen.
- **Sync between Macs**: Settings ▸ Account ▸ Sync Sidebar (both Macs signed in to the same Apple ID).
- **Something is wrong**: Help ▸ Troubleshooting, or [open an issue](https://github.com/St0neWan9/open-arc-browser/issues).
- [Tips for organizing](organizing.md)
