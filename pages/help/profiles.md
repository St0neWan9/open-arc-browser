# Profiles

Profiles keep your data separate across Spaces: history, logins, cookies and extensions. Every
Space uses one Profile, and a Profile can be used by several Spaces.

- Create, rename or delete Profiles in Settings ▸ Profiles. The Default Profile cannot be deleted.
- Choose a Space's Profile when you create the Space, or from the Space's ⋯ menu ▸ Set Profile.
- Each Profile has its own search engine, tab archiving time and download folder.
- Profiles are not synced between Macs; a synced Space uses the Default Profile on a Mac that does
  not have its Profile.
